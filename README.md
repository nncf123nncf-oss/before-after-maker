# ビフォーアフター比較画像メーカー

Before写真とAfter写真を選ぶだけで、ラベルと中央の区切り線を入れた1枚の比較画像を作るツールです。

100日100プロダクトチャレンジ Day039。

## 解決する困りごと

- 想定利用者: 施術（整体・エステ・美容）・リフォーム・整理収納・清掃など、作業の効果を写真で見せたい事業者
- 困りごと: Before写真とAfter写真をSNSに2枚バラバラで投稿すると効果が伝わりにくい
- 解決方法: 写真を2枚選ぶだけで、ラベルと区切り線つきの比較画像を1枚のPNGとして保存できる

## 使い方

1. 「Before（作業前）の写真」を選ぶ
2. 「After（作業後）の写真」を選ぶ
3. ラベルの言葉を `Before/After`（英語）か `ビフォー/アフター`（日本語）から選ぶ
4. 画像の形を「正方形」（1080×1080）か「横長」（1080×608）から選ぶ
5. 「PNGで保存」を押す

## 機能

- Before画像・After画像の2枚選択
- 左右連結・ラベル帯（Before側はグレー、After側は青）・中央区切り線の描画
- ラベルの日本語／英語切替
- 正方形（1080×1080）／横長（1080×608）の2比率でPNG保存
- 写真が片方でも選ばれていない状態で保存を押したときの赤文字エラー表示

## 作っていないもの

- スライダーで境界を動かす比較UI
- ラベル文言の自由入力（Before/After固定＋日本語／英語切替のみ）

## 技術

- HTML / CSS / JavaScript の1ファイル（`index.html`）
- ビルドなし・npmなし・CDNなし・外部通信なし
- 画像はブラウザの中だけで処理し、外部へ送信しません
- canvas の `drawImage`（中央基準クロップ）・`fillRect`・`fillText` のみで描画
- 保存は `canvas.toDataURL('image/png')`

## 既知の制約

- 極端に縦横比が違う写真は、中央基準でクロップされるため端が切れます（余白は出ません）
- 保存されるPNGのサイズは1080×1080または1080×608の固定です
- 選んだ写真は保存されません（ページを再読み込みすると選び直しになります）
